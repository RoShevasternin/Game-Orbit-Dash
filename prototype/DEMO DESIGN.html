07 · GL ES 2.0 — ПРАВИЛА РЕАЛІЗАЦІЇ

  • Білий атлас + tint. glow / ball / highlight / gem / spike / spike-core / particle — білі; колір через batch.setColor(theme.role). Зміна теми = заміна 5 Color, нуль текстур.
  • Плавний перехід теми: тримай current+target палітри, Color.lerp(target, 8f*dt) для всіх 5 ролей.
  • Glow-прохід additive (SRC_ALPHA, ONE) до ядер; далі bloom: bright-pass → gaussian ping-pong FBO ½→¼ → additive composite.
  • ShapeDrawer (колір-аргумент): кільця, пунктир (фаза = офсет сегментів або шейдер fract(atan·k−u_t)), дуга комбо, стрілка, піпси, гекс-контур.
  • Шейдери-квади: фон (радіальний градієнт u_bgColor + 2 октави noise, дихання від швидкості), віньєтки станів (radial-alpha, u_color), flash/dim — прості квади.
  • Трейл — Mesh triangle-strip 24×2 з vertex-кольорами (градієнт безкоштовно), другий пас ×2.1 ширини під glow.
  • Бюджет: атлас ≤1024², 3 FBO, ~6 шейдерів; фолбек — вимкнути bloom, контраст ролей тримає читабельність.
