## Стан на 7 вересня 2026

**Система рендеру фігур і ефектів добудована й перевірена на пристрої.** Один інваріант
замість трьох різних відповідей на «якого воно розміру»:

> Межі актора = сама фігура. Поле msdf і ефекти малюються ЗА межами.

- `AMsdfImage` — `setSize` / `fillParent` = розмір фігури, як у Figma
- `VfxTexture` / `VfxGroup` — `bleed`, поле під ефект назовні; **рахується сам** із
  ланцюга `post` (`VfxEffect.reachTexels()`)
- треба врахувати ефект у розкладці — `tex.outerWidth × tex.outerHeight`
- деталь на всіх одна — `OverflowImage`; `VfxImage` отримав параметр `inner`

Заміряно на пристрої (1080×2400, 3 px/юніт): вектор 186×101 — перехід краю 1 px;
`glow.image()` — світіння виходить за межі й гасне за ~15 юнітів при `bleed` 19;
`Image(region)` на `outer` 224×139 — світіння всередині. 61 FPS, ореолу немає.

Шлях сюди — `decisions.md`: MSDF-конвеєр (14), відмова від 9-patch, видалення `ACircle` /
`CircleEffect` / `PolygonEffect` / `AMsdfGroup` (15, 15c), запікання край-у-край (15d),
`bleed` (15e), автоматичний `bleed` (15f).

### Хвости — прибрати перед грою

- `SpriteUtil.Msdf.aaa` + `aaaGlow` — тестова несиметрична фігура
- `TestScreen.addMsdfSandbox()` — тимчасовий стенд
- `assets/msdf/svg/aaa.svg` (+ `png/aaa.png`), потім перегенерувати атлас
- `docs/patches/15*.md` — усі застосовані, можна прибрати гуртом
