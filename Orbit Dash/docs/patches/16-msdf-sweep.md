# 16 — `svg/` як єдине джерело правди для MSDF-атласу

## Що і навіщо

Щоб прибрати фігуру з атласу, зараз треба видалити файл **у двох папках** —
`assets/msdf/svg/` і `assets/msdf/png/`. Забув другу — мертва фігура їде в атлас далі.

Причина не в тому, що папок дві, а в тому, що `png/` — **похідний кеш**, який ніхто не
підмітає. `gen-msdf.sh` іде по `svg/*.svg` і перезаписує тільки те, для чого є SVG;
файли без пари він не бачить. `pack-msdf.py` потім бере `png/*.png` і чесно пакує все,
що знайшов, — разом із сиротами.

Патч додає в `gen-msdf.sh` підмітання перед генерацією: `png/x.png` без `svg/x.svg`
видаляється, з рядком у логу. Після цього `svg/` — єдине місце, де фігура з'являється
й зникає.

Заразом — захист від порожньої `svg/`: без нього glob лишається текстом `svg/*.svg`,
і msdfgen падає з незрозумілим повідомленням про неіснуючий файл.

`pack-msdf.py` **не чіпаємо**: він і має пакувати все, що лежить у `png/`. Правда про
склад атласу тепер в одному місці, а не розмазана між двома скриптами.

## Куди

**Файл:** `/Users/admin/Apps/Game Orbit Dash/assets/msdf/gen-msdf.sh`

## Що робити

**ЗАМІНИТИ** цей фрагмент:

```sh
mkdir -p png
for f in svg/*.svg; do
    n=$(basename "$f" .svg)
```

на код нижче. Решта файла — без змін.

## Код

```sh
mkdir -p png

# png/ — похідний кеш, єдине джерело правди — svg/. Цикл нижче перезаписує лише те,
# для чого є SVG, тож видалений SVG лишав би своє поле тут — а pack-msdf.py чесно
# запакував би його в атлас. Тому спершу підмітаємо сиріт: фігуру прибирають
# в ОДНОМУ місці — видаленням SVG.
for p in png/*.png; do
    [ -e "$p" ] || continue                  # порожня папка: glob лишається текстом
    n=$(basename "$p" .png)
    [ -f "svg/$n.svg" ] || { echo "✕ прибрано зайве: $n.png"; rm "$p"; }
done

for f in svg/*.svg; do
    [ -e "$f" ] || { echo "svg/ порожня — нема чого генерувати"; exit 1; }
    n=$(basename "$f" .svg)
```

## Перевірка

```bash
cd "/Users/admin/Apps/Game Orbit Dash/assets/msdf"
touch png/zombie.png          # сирота без SVG
sh gen-msdf.sh                # має надрукувати: ✕ прибрано зайве: zombie.png
python3 pack-msdf.py          # у msdf.atlas нема регіона zombie
```

Або по-справжньому: подвійний клік на `gen-msdf.command` — він викликає обидва скрипти
з правильними `PXRANGE`/`DIM` і кладе атлас у `app/src/main/assets/atlas/`.

на машині без `msdfgen`/brew. Сиріт там після цього патча не буває.

```

```

(`SpriteUtil.kt:108`). Повідомлення зрозуміле, але це рантайм — видаляючи SVG, забирай
і поле.
